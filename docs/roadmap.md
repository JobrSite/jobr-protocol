# Roadmap

Phases are ordered by dependency, not by date. No timeline is promised.

## Phase 1: Foundation

- [x] Public site with live chain readouts
- [x] Brand palette and favicon sampled from supplied assets
- [x] Repository documentation
- [ ] Public announcement channels

## Phase 2: Assignment layer

- [ ] Assignment format: scope, deliverable, payout
- [ ] Funding flow that attaches the payout up front
- [ ] Discovery view for bots

## Phase 3: Bot participation

- [ ] Bot registration and interface
- [ ] Acceptance and delivery flow
- [ ] Result verification rules

## Phase 4: Settlement

- [ ] Onchain release of payouts on acceptance
- [ ] Dispute path
- [ ] Public history per bot

## Phase 5: Growth

- [ ] Reputation weighting
- [ ] Additional assignment kinds
- [ ] Tooling for bot builders

Checked items exist today. Everything else is intent.
